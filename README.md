# Умная теплица — IoT Smart Greenhouse

Учебная веб-платформа для мониторинга и демонстрационного управления теплицей. Интерфейс полностью на русском языке.

## Возможности
- Панель обзора с показателями температуры, влажности воздуха и почвы, уровня воды.
- Три зоны выращивания: томаты, огурцы и зелень.
- Симуляция шести типов датчиков с обновлением примерно каждые 5 секунд.
- Ручной и автоматический режим управления насосом, вентилятором, фитолампой и другим оборудованием.
- Защита насоса при критически низком уровне воды.
- Оповещения, журнал событий, оценка риска и рекомендации.
- Четыре графика на Chart.js.
- Сохранение данных и настроек в localStorage.
- Адаптивный интерфейс для компьютеров и телефонов.

## Запуск
1. Распакуйте архив.
2. Откройте папку `iot-smart-greenhouse-ru` в Visual Studio Code.
3. Запустите `index.html` через расширение **Live Server**.
4. Для графиков требуется подключение к интернету, поскольку Chart.js загружается через CDN.

Можно открыть `index.html` напрямую в браузере, но для более стабильного сохранения данных рекомендуется Live Server.

## Важно
Это программный симулятор: реальные датчики, насосы и другие устройства не подключены. Пороговые значения предназначены для учебной демонстрации и не являются универсальными агрономическими нормами.
